Register, select, and sample deterministic fixed-point ground-height layers for
one `TrailblazerWorldContext`. Heightmap services do not discover terrain or
perform hidden Navigator probes; hosts own baking, registration, and the point
at which a controller applies a sample.

See the
[heightmap guide](https://github.com/mrdav30/Trailblazer/wiki/HeightMaps) for
compression, multi-level selection, adapter baking, and grounding behavior.
