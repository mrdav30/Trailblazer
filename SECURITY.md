# Reporting a security issue

Report suspected vulnerabilities privately to `david.oravsky@gmail.com`. Include
the affected package and version, the impact, and a small reproduction with
credentials and personal data removed. Mention whether the issue also occurs on
the latest stable release and which package family you use.

Coordinate disclosure privately before opening a public issue. For usage
questions and ordinary bugs, see [Support](.github/SUPPORT.md).
